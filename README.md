# Crypto CTF Roadmap

This repository contains a structured 5-weeks roadmap for learning practical cryptography with a focus on CTF preparation. It covers fundamental cryptographic concepts, symmetric and asymmetric cryptography, RSA, Diffie-Hellman, ECC, and common cryptographic attacks.

Each week includes selected learning resources and practical CTF challenges to reinforce the concepts and build hands-on problem-solving skills.

## Roadmap

- [Week 1 — Encoding, XOR & Math Basics](Week-1/Roadmap.md)
- [Week 2 — Symmetric Cryptography](Week-2/Roadmap.md)
- [Week 3 — RSA & Digital Signatures](Week-3/Roadmap.md)
- [Week 4 — Diffie-Hellman & ECC Basics](Week-4/Roadmap.md)
- [Week 5 — ECDH, ECDSA & ECC Attacks](Week-5/Roadmap.md)

> The roadmap is a work in progress and may be updated as the learning path evolves.
