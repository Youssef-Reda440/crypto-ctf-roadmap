# Week 1 — Encoding, XOR & Math Basics

## What You'll Learn

- Common data encodings used in cryptography and CTFs.
- XOR and its common properties and applications.
- Essential mathematical concepts used throughout cryptography.

## Description

This week focuses on the fundamental concepts needed to start solving cryptography challenges. You will learn how common encodings work, understand XOR-based operations, and build the basic mathematical foundation required for topics such as RSA and Diffie-Hellman.

---

## Topics

#### Encoding

- ASCII
- Hexadecimal
- Base64
- Bytes & Integers

#### XOR

- XOR Basics
- XOR Properties
- Single-Byte XOR

#### Math Basics

- Modular Arithmetic
- GCD
- Extended Euclidean Algorithm
- Modular Inverse
- Modular Exponentiation
